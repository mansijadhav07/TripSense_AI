- Process: Find seed hotel from user history → find similar hotels
- Problem: Feature-similar hotels ≠ user-preference-similar

- Reason: Features don't correlate with actual user taste
- Result: Near-zero overlap → 0.0 metrics (honest result)
- Fix Needed: Better feature engineering
